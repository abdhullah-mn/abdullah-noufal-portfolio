# Abdhullah Noufal Portfolio

## Goal
Build a polished, responsive one-page portfolio that presents Abdhullah as a capable IT undergraduate seeking his first Software Engineering Internship.

## Experience
- Fixed navigation with monogram, section links, internship-status cue, and mobile menu.
- Dark editorial developer aesthetic inspired by the reference: confident typography, restrained coral/cyan accents, subtle grid details, selective glass surfaces, and minimal motion.
- Hero with Abdhullah’s name, role, internship availability, project/contact actions, social links, a clearly labeled profile-photo placeholder, and a compact code-style status panel.
- Concise About and Education areas emphasizing University of Moratuwa, graduation date, problem solving, maintainable software, and SOLID principles.
- Categorized skills display highlighting JavaScript/TypeScript and full-stack breadth without skill percentages.
- Full-Stack Development specialization section describing capabilities without overstating professional experience.
- Strong Projects section with Auto Matrix featured, accurate “under development” treatment for Social Media Post Automation, and backend-focused Green Cart coverage.
- Engineering philosophy callout: “Build. Learn. Improve.”
- Contact area with clickable email, phone, LinkedIn, and GitHub links plus a validated contact form that opens the visitor’s email app.
- Footer with role summary, social links, and copyright.

## Interaction and Quality
- Smooth anchor navigation, active mobile menu behavior, scroll-reveal motion, restrained card interactions, and reduced-motion support.
- Accessible semantic structure, visible focus states, readable contrast, touch-friendly controls, and responsive layouts across desktop, tablet, and mobile.
- Route-specific SEO and social metadata.
- No invented employment, credentials, project outcomes, repository URLs, or profile likeness.

## Technical Details
- Implement in the existing TanStack Start home route with reusable React sections.
- Define the complete visual token system in the global Tailwind CSS file using semantic OKLCH colors.
- Use inline developer motifs and icons; the uploaded screenshot remains reference-only.
- Keep project GitHub controls disabled or directed to the main GitHub profile until repository URLs are supplied.
- Validate contact fields in the browser before constructing the encoded email link; no messages are stored or sent by a server.
- Verify build status and render at desktop and mobile sizes before completion.
