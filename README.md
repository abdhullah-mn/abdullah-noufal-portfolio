# Abdhullah's Dev Hub

take this mage as an example,
Create a modern, visually polished personal portfolio website for **Abdhullah Noufal**, a B.Sc. (Hons) in Information Technology student at the **University of Moratuwa**, Sri Lanka. He is an aspiring Software Engineer and passionate problem solver currently seeking his **first Software Engineering Internship**.

Abdhullah has a strong foundation in software development, with experience across frontend, backend, databases, APIs, version control, and containerization. His primary specialization is **Full-Stack Development**, with a focus on building reliable, maintainable software and continuously improving engineering practices using principles such as **SOLID design principles**.

The website should communicate three key qualities: **technical capability, problem-solving mindset, and strong potential as an emerging software engineer**. It should feel professional enough for recruiters and engineering teams while still having a modern, distinctive developer aesthetic.

Use a professional profile picture prominently on the homepage. The profile image should be presented in a clean, modern developer-style treatment without excessive effects.

## 1. Overall Design Direction

Use a **dark, modern developer aesthetic**.

Visual direction:

* Dark background with sophisticated neutral tones.
* Subtle gradients and restrained technology-inspired accents.
* Clean glassmorphism elements where appropriate.
* Modern typography with excellent readability.
* Spacious layouts with strong visual hierarchy.
* Subtle animations and micro-interactions.
* Smooth scrolling between sections.
* Minimal but meaningful decorative elements inspired by software development, code, grids, or digital interfaces.
* Avoid excessive neon effects, clutter, or overly flashy animations.
* Maintain a professional appearance suitable for a software-engineering internship portfolio.

The design should feel like a combination of a **professional engineering portfolio and a modern developer landing page**.

Ensure the website is:

* Fully responsive across desktop, tablet, and mobile.
* Accessible and readable.
* Fast-loading and performance-conscious.
* SEO-friendly.
* Consistent in spacing, typography, buttons, cards, icons, and animations.
